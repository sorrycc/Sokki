# Sokki — Design Document

**Date:** 2026-03-20
**Status:** Approved
**Scope:** Essential Core (v1)

## Overview

Sokki is a native macOS text expander inspired by [espanso](https://espanso.org), built with the technology stack from [thor-clone/HotApp](https://github.com/user/thor-clone). It monitors keystrokes system-wide, detects trigger keywords, and replaces them with expanded text.

## Decisions Summary

| Aspect | Decision |
|--------|----------|
| **Stack** | Swift 6, SPM, SwiftUI + AppKit, macOS 14+ |
| **Dependencies** | Yams (YAML parsing) only |
| **Architecture** | Single monolithic menu bar app (LSUIElement) |
| **Detection** | CGEvent tap on dedicated thread, secure input detection |
| **Matching** | Rolling ring buffer (128 chars), trie-based lookup, longest-match-wins |
| **Injection** | Auto mode: key simulation <= threshold, clipboard above, undo support |
| **Variables** | `{{clipboard}}`, `{{date:%Y-%m-%d}}` — double-brace syntax |
| **Config** | YAML, own format at `~/.config/sokki/`, FSEvents watcher with debounce, atomic reload |
| **Clipboard** | Full pasteboard snapshot/restore (all types: string, RTF, images, files) |
| **Logging** | Rotating log file at `~/.config/sokki/logs/`, error by default, debug opt-in |
| **UI** | NSStatusItem menu bar + minimal SwiftUI settings window |
| **Permissions** | Accessibility only |
| **App Name** | Sokki |

## Data Models

### Match YAML Format

```yaml
# ~/.config/sokki/match/default.yml
matches:
  - trigger: ":hello"
    replace: "Hi there!"

  - trigger: ":sig"
    replace: "Best regards,\n{{clipboard}}"

  - trigger: ":now"
    replace: "Current time: {{date:%Y-%m-%d %H:%M}}"

  - trigger: ":shrug"
    replace: "¯\\_(ツ)_/¯"

  # Disabled match (won't expand until enabled: true or field removed)
  - trigger: ":draft"
    replace: "This is a work in progress"
    enabled: false
```

**Match fields:**
- `trigger` (required) — the keyword to detect
- `replace` (required) — the replacement text
- `enabled` (optional, default: `true`) — set `false` to disable without deleting

### Global Config

```yaml
# ~/.config/sokki/config/default.yml
enable: true
clipboard_threshold: 50          # chars before switching to clipboard mode
inject_delay: 0                  # ms between key simulations
paste_shortcut: "Cmd+V"
preserve_clipboard: true
restore_clipboard_delay: 100     # ms
log_level: "error"               # "error" (default) or "debug"
toggle_shortcut: "double_option" # double-tap Option to toggle, or "none" to disable
```

### Swift Models

```swift
struct Match: Identifiable, Codable, Sendable {
    let id: UUID
    var trigger: String           // ":hello"
    var replace: String           // "Hi there! {{date:%H:%M}}"
    var isEnabled: Bool           // maps to YAML "enabled" field, default true
}

enum VariableType: Sendable {
    case date(format: String)     // {{date:%Y-%m-%d}}
    case clipboard                // {{clipboard}}
}

struct AppConfig: Codable, Sendable {
    var isEnabled: Bool = true
    var clipboardThreshold: Int = 50
    var injectDelay: Int = 0
    var pasteShortcut: String = "Cmd+V"
    var preserveClipboard: Bool = true
    var restoreClipboardDelay: Int = 100
    var logLevel: String = "error"              // "error" or "debug"
    var toggleShortcut: String = "double_option" // or "double_shift", "double_control", "none"
}
```

**Config directory:** `~/.config/sokki/`
- `config/default.yml` — global settings
- `match/` — match definition files (all `.yml` files loaded alphabetically)
- `logs/sokki.log` — rotating log file (1MB cap)

**Match file conflict resolution:**
- Files in `match/` loaded in alphabetical order (e.g., `default.yml` before `work.yml`)
- If two files define the same trigger, last file wins (later overrides earlier)
- Duplicate triggers logged as warnings (visible in log file and menu bar tooltip)

## Engine Design

### Keystroke Capture Flow

```
CGEvent tap (keyDown events) — on dedicated thread
    |
KeystrokeMonitor extracts character + key code
    |
TapContext (OSAllocatedUnfairLock-guarded, on tap thread)
  ├── suppressMatching flag set? → pass through (injection in progress)
  ├── SecureInputMonitor: IsSecureEventInputEnabled()? → skip
  ├── Paste detected (Cmd+V)? → suppress buffer for 200ms
  ├── Toggle shortcut detected (double-tap Option)? → toggle enabled state
  ├── RollingBuffer appends character (ring buffer, 128 chars)
  ├── TrieMatcher walks trie with new character
  └── Match found?
        |
        ├── YES → dispatch to main:
        │   1. Set suppressMatching = true
        │   2. VariableRenderer expands replacement
        │   3. TextInjector outputs (backspace + inject)
        │   4. Set suppressMatching = false
        │   5. UndoManager stores (trigger, replacement) for undo
        └── NO → continue
```

### KeystrokeMonitor

- Runs CGEvent tap on dedicated thread (same pattern as thor-clone's ShortcutManager)
- Captures `.keyDown` events, extracts Unicode characters via `CGEvent.keyboardGetUnicodeString()`
- Tracks modifier state (skip expansion when Cmd/Ctrl held)
- All buffer/matching logic runs on the tap thread via TapContext (no main actor round-trip)
- Only dispatches to main for injection and UI updates
- Re-enables tap on `.tapDisabledByTimeout` / `.tapDisabledByUserInput` (same as thor-clone)

### TapContext

- `@unchecked Sendable` with `OSAllocatedUnfairLock` (same pattern as thor-clone's TapContext)
- Owns: RollingBuffer, TrieMatcher, SecureInputMonitor state
- Single lock acquisition per keystroke — sub-microsecond critical section
- Keeps all hot-path work off the main thread

### RollingBuffer

- Fixed-size ring buffer of characters (128 chars)
- Append-only during normal typing
- Cleared on: mouse click, modifier key combos, app focus change
- Provides `tail(_ count: Int) -> String` for trie verification

**Focus change buffer clearing:**
- Observe `NSWorkspace.didActivateApplicationNotification` in AppDelegate
- On notification, dispatch buffer clear + trie cursor reset to tap thread via TapContext
- Prevents cross-app trigger leakage (e.g., typing `hel` in Safari, switching to Terminal, typing `lo` should NOT trigger `:hello`)

### TrieMatcher

Replaces linear scan with a trie (prefix tree) for O(1)-per-keystroke matching:

```
Trie structure (built from triggers):
    root
    ├── ':' → 'h' → 'e' → 'l' → 'l' → 'o' → MATCH(":hello")
    ├── ':' → 's' → 'i' → 'g' → MATCH(":sig")
    ├── ':' → 's' → 'h' → 'r' → 'u' → 'g' → MATCH(":shrug")
    └── ':' → 'n' → 'o' → 'w' → MATCH(":now")

On each keystroke:
  1. Feed character to all active cursors in the trie
  2. Advance cursors that match, drop those that don't
  3. Start a new cursor at root (for new potential matches)
  4. If any cursor reaches a match node:
     a. Are there still active cursors with longer potential matches?
        YES → mark as "pending match", continue collecting keystrokes
        NO  → fire immediately
  5. Pending match fires when:
     - No more active cursors remain (all dropped), OR
     - A non-advancing keystroke arrives (character doesn't continue any cursor)
```

**Prefix disambiguation example:**
Triggers `:he` and `:hello` both exist.
```
User types ':' → cursor starts at root, advances to ':'
User types 'h' → cursor at ':h'
User types 'e' → cursor at ':he' → MATCH node! But ':hello' is still possible
  → mark pending match ":he", keep cursor alive
User types 'l' → cursor at ':hel' → pending match still held
User types 'l' → cursor at ':hell' → pending match still held
User types 'o' → cursor at ':hello' → MATCH node, no longer children
  → fire ":hello" (longest), discard pending ":he"
```
If instead after `:he` the user types a space:
```
User types ' ' → no cursor can advance → fire pending ":he"
```

- Rebuilt when config reloads (swap via atomic reference)
- Multiple concurrent cursors handle overlapping trigger prefixes

### SecureInputMonitor

- Checks `IsSecureEventInputEnabled()` on each keystroke (cheap C call)
- When secure input is active (password fields, etc.):
  - Skip all matching and buffer updates
  - Update menu bar icon to dimmed state (dispatch to main)
- When secure input ends:
  - Clear buffer (don't carry stale chars across security boundary)
  - Restore normal icon

### TextInjector (Auto Mode)

```
replacement.count <= clipboardThreshold?
├── YES -> Key simulation mode
│   For each char: CGEvent(keyboardEvent) -> post to HID
│   With injectDelay between chars
└── NO -> Clipboard mode
    1. ClipboardManager.snapshot()   — save ALL pasteboard items + types
    2. NSPasteboard.general.setString(replacement)
    3. Simulate Cmd+V via CGEvent
    4. After restoreClipboardDelay -> ClipboardManager.restore()  — restore full snapshot
```

### Backspace Handling

Before injecting, simulate `backspace x trigger.count` to erase the typed trigger, then inject the replacement text.

### Undo Support

Simple last-expansion undo via backspace:

```swift
struct ExpansionRecord {
    let trigger: String          // what was typed
    let replacement: String      // what was injected
    let timestamp: Date
}
```

- After expansion, store one `ExpansionRecord`
- Track subsequent backspace count
- If user presses backspace `replacement.count` times within 3 seconds of expansion:
  - Detected as undo intent
  - Inject original trigger text back
  - Clear the record
- Any non-backspace keystroke clears the record
- Only tracks the most recent expansion (no deep undo stack)

### Injection Suppression

Prevents self-expansion loops and paste-triggered false matches:

**Self-expansion suppression:**
- `TapContext` owns a `suppressMatching: Bool` flag
- Before `TextInjector` starts (backspace + inject), set flag to `true`
- Tap callback checks flag first — if `true`, pass keystroke through without buffering or matching
- After injection completes, set flag to `false`
- Prevents injected characters from triggering further expansions (e.g., expanding `:hello` → "Hi there!" won't match a trigger containing "hi")

**Paste event suppression:**
- Detect Cmd+V in tap callback (check modifier flags + keycode 0x09)
- On detection, set `pasteSuppressionUntil = now + 200ms`
- While `Date() < pasteSuppressionUntil`, skip buffer appending
- Prevents pasted text containing trigger strings from firing expansions
- 200ms window covers the paste event delivery; subsequent real typing resumes matching

### Toggle Hotkey

Quick enable/disable without clicking menu bar:

- **Config:** `toggle_shortcut: "double_option"` (default) or `"double_shift"`, `"double_control"`, `"none"`
- **Detection:** In tap callback, track modifier-only key events (flagsChanged event type)
  - Record timestamp of last modifier press
  - If same modifier pressed again within 300ms → toggle
- **On toggle:**
  - Flip `AppConfig.isEnabled`
  - Dispatch to main: update menu bar icon (normal ↔ disabled state)
  - Clear buffer and trie cursors
  - Log toggle event

## Variable Rendering

**Syntax:** `{{variable}}` or `{{variable:params}}` inline in replacement strings.

**Parser:** Regex scan: `\{\{(\w+)(?::([^}]*))?\}\}`

**Built-in variables for v1:**

| Variable | Syntax | Example Output |
|----------|--------|----------------|
| `{{clipboard}}` | `{{clipboard}}` | (current clipboard content) |
| `{{date}}` | `{{date:%Y-%m-%d %H:%M}}` | `2026-03-20 14:30` |
| `{{date}}` | `{{date}}` (no params) | `2026-03-20` (default format) |

**Design decisions:**
- `{{var}}` double-brace syntax — unambiguous delimiters, no conflict with shell `$` or YAML special chars, easy to parse
- Colon separates variable name from params (no parentheses to confuse syntax highlighters)
- Extensible: adding new variable types means adding a case to a switch
- Unknown variables left as-is (no crash, no silent removal)

```
│                                               │
└───────────────────────────────────────────────┘
```

**Behavior:**
- Editing via UI writes back to YAML files
- "Reload Config" re-parses all YAML files (for users who edit files directly)
- Config file watcher via **FSEvents** (not DispatchSource) — catches new/deleted files in `match/` directory
- **Debounced reload** (300ms) — editors trigger multiple write events per save, debounce avoids partial reads
- **Atomic config reload** — build new match list + trie in temporary collection, validate, then swap atomically. If any YAML file has a syntax error: show error in menu bar tooltip, keep previous working config
- Menu rebuilds lazily via `NSMenuDelegate` (same as thor-clone)
- Settings window opened via notification bridge (Window scene, not Settings scene, for LSUIElement apps)

## Permissions & App Lifecycle

### Required Permissions

- **Accessibility** — CGEvent tap needs it. Check via `AXIsProcessTrustedWithOptions()` on launch, show alert if denied.
- **Input Monitoring** — macOS Sonoma+ requires this separately for event taps. Bundled with Accessibility prompt.

### App Lifecycle

```
Launch
  |
AppDelegate.applicationDidFinishLaunching()
  ├── Bootstrapper.run() (create config dir + examples on first launch)
  ├── Check accessibility permission (prompt if needed)
  ├── Create StatusItemController (menu bar icon)
  ├── ConfigLoader.loadAll() (read ~/.config/sokki/)
  │   ├── Load match/*.yml in alphabetical order
  │   ├── Resolve duplicate triggers (last wins, log warnings)
  │   └── Build initial TrieMatcher from loaded matches
  ├── Start FSEvents watcher on config directory (with 300ms debounce)
  ├── Observe NSWorkspace.didActivateApplicationNotification (buffer clear)
  └── KeystrokeMonitor.start() (begin CGEvent tap)

Running
  ├── CGEvent tap captures keystrokes (on tap thread)
  │   ├── TapContext: check secure input → buffer → trie match
  │   ├── Secure input active → skip matching, dim icon
  │   ├── Match found → check prefix disambiguation (pending vs fire)
  │   └── Fire match → dispatch to main → render → inject → store undo record
  ├── App focus change → dispatch buffer clear + cursor reset to tap thread
  ├── FSEvents detects config change → debounce 300ms → atomic reload
  │   └── Parse all YAML → validate → build new trie → swap atomically
  │       └── On error: keep old config, show error in menu bar tooltip, log error
  ├── Menu bar toggle → KeystrokeMonitor.stop()/start()
  └── Settings UI edits → write YAML → FSEvents auto-reloads

Quit
  └── KeystrokeMonitor.stop(), FSEvents cleanup
```

### App Configuration

- **LSUIElement:** `true` in Info.plist — no Dock icon, menu bar only
- **Launch at Login:** `SMAppService.mainApp` toggle in Settings

## Clipboard Manager

Full pasteboard snapshot/restore to avoid losing rich content:

```swift
struct PasteboardSnapshot {
    let items: [PasteboardItem]     // ordered list of items
    let changeCount: Int            // NSPasteboard.changeCount at snapshot time
}

struct PasteboardItem {
    let types: [NSPasteboard.PasteboardType]
    let data: [NSPasteboard.PasteboardType: Data]   // raw data per type
}
```

**Snapshot:** Iterate `NSPasteboard.general.pasteboardItems`, for each item read `data(forType:)` for every declared type. Preserves strings, RTF, images, file URLs, custom types.

**Restore:** Check `changeCount` — if clipboard was modified externally between snapshot and restore (user copied something else), skip restore to avoid overwriting their new content. Otherwise, clear pasteboard and write back all items with all types.

## Logging

```swift
final class Logger {
    static let shared = Logger()

    enum Level: Int, Comparable { case error = 0, debug = 1 }

    func error(_ message: String)   // always logged
    func debug(_ message: String)   // only if log_level == "debug"
}
```

- **File:** `~/.config/sokki/logs/sokki.log`
- **Rotation:** When file exceeds 1MB, rename to `sokki.log.1` and start fresh (keep 1 backup)
- **Format:** `[2026-03-20 14:30:05] [ERROR] Failed to parse match/work.yml: ...`
- **What to log:**
  - ERROR: YAML parse failures, CGEvent tap failures, permission issues, injection errors
  - DEBUG: Each keystroke processed, matches found, config reloads, clipboard operations
- **Menu bar:** Add "Show Log" item → opens log file in Console.app (`NSWorkspace.open()`)

## First-Launch Bootstrapping

On launch, `Bootstrapper` checks if `~/.config/sokki/` exists:

**If missing (first launch):**
1. Create directory structure: `config/`, `match/`, `logs/`
2. Write `config/default.yml` with default settings (commented)
3. Write `match/default.yml` with example matches:

```yaml
# Sokki — Example matches
# Edit this file or add more .yml files in this directory.
# Changes are auto-detected and reloaded.

matches:
  # Simple text replacement
  - trigger: ":hello"
    replace: "Hi there!"

  # Insert current date
  - trigger: ":today"
    replace: "{{date:%Y-%m-%d}}"

  # Insert clipboard content with wrapper
  - trigger: ":paste"
    replace: "Pasted: {{clipboard}}"

  # Multi-line replacement
  - trigger: ":sig"
    replace: |
      Best regards,
      Your Name
```

4. Show welcome `NSAlert`:
   - Title: "Welcome to Sokki"
   - Message: "Config files created at ~/.config/sokki/. Edit match/default.yml to add your triggers."
   - Buttons: "Open Config Folder" | "OK"

**If exists:** Skip silently.
