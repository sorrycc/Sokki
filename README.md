# Sokki

macOS 14+ menu bar text expander. (速記 — "shorthand".)

## Build

```bash
swift build                  # debug
swift build -c release       # release
./Scripts/package_app.sh     # bundle Sokki.app (ad-hoc signed)
```

Then `cp -r Sokki.app /Applications/`.
